LOAD & EQUIPMENT

Weight arrangement guide

1. Weight-stack machines

  1. Sit or stand in the correct position and adjust seat/pads.
  2. Check the pin and stack are fully settled.
  3. Insert the selector pin completely into the chosen plate.
  4. Start with a light load; test one controlled repetition.
  5. Do not move the pin while the stack is lifted.

2. Barbell plate loading

  1. Use a stable rack and check the bar and collars.
  2. Load matching plates on both sides: same weight and order.
  3. Slide each plate fully onto the sleeve.
  4. Secure both sides with collars before lifting.
  5. Unload evenly, alternating sides, with the bar safely racked.

Never leave an unevenly loaded bar unattended or lift without collars where they are required.

3. Dumbbells & kettlebells

  1. Choose a pair with equal weight.
  2. Check handles, heads and locking mechanisms.
  3. Pick up and put down with a stable stance.
  4. Return weights to labelled rack spaces; do not drop them.

4. Plates on plate-loaded machines

  1. Check the machine is empty and stable before loading.
  2. Load equal weight on left and right horns.
  3. Keep plates fully seated and use retaining clips if supplied.
  4. Adjust the seat and safety stops before starting.
  5. Unload both sides evenly after racking the machine.
